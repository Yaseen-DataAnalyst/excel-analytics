لوحة تحكم أداء المبيعات – Excel Dashboard
=========================================

نظرة عامة
---------
هذا المشروع عبارة عن لوحة تحكم تفاعلية (Dashboard) لتحليل أداء المبيعات،
تم بناؤها باستخدام Microsoft Excel بالاعتماد على PivotTables وPivotCharts وSlicers.
يقوم المشروع بتحويل بيانات المبيعات الخام إلى تقرير مرئي واضح وتفاعلي،
يساعد مديري المبيعات على متابعة الإيرادات حسب المنتج ومندوب المبيعات بشكل فوري.

الهدف من المشروع
-----------------
كان الهدف هو تطبيق وإظهار المهارات التالية:
  - تلخيص مجموعات كبيرة من البيانات باستخدام الجداول المحورية (PivotTables).
  - عرض المؤشرات الرئيسية بشكل مرئي باستخدام المخططات المحورية (PivotCharts).
  - إضافة تفاعلية المستخدم من خلال أدوات التقطيع (Slicers).
  - تصميم لوحة تحكم احترافية ومرتبة في صفحة واحدة داخل Excel.

الأدوات والمهارات المستخدمة
-----------------------------
  - Microsoft Excel
    - PivotTables (جداول محورية متقاطعة، إعدادات الحقول)
    - PivotCharts (مخطط عمودي مجمع)
    - Slicers (تصفية حسب مندوب المبيعات، المنتج)
    - تنسيق وتخطيط لوحة التحكم
  - SQL (تم استخدامها لاستخراج وتجهيز البيانات الخام قبل استيرادها إلى Excel)

أبرز الخصائص
-------------
  - جدول مبيعات متقاطع: إجمالي المبيعات لكل مندوب وكل منتج.
  - مخطط بياني: مقارنة مرئية للمبيعات عبر المندوبين والمنتجات.
  - أدوات تقطيع (Slicers): تصفية بنقرة واحدة لعرض بيانات مندوب معين أو منتج معين.
  - تصميم مرتب: لوحة تحكم من صفحة واحدة تحتوي على عنوان رئيسي وأرقام ومخططات.

ملفات المشروع
--------------
  - sales_data.xlsx – البيانات الخام (عينة من عمليات البيع).
  - Dashboard.xlsx – ملف لوحة التحكم التفاعلية النهائي.
  - screenshots – مجلد يحتوي لقطات شاشة للوحة التحكم.

أمثلة على الرؤى المستخلصة
---------------------------
  - المنتج الأعلى مبيعاً هو Laptop (بإجمالي 684 ألف).
  - المندوبة Alice تحقق أعلى مبيعات التابلت، بينما Bob يتصدر مبيعات الطابعات.
  - تسمح لوحة التحكم بتصفية أي مندوب لتحليل أدائه في كل منتج خلال ثوانٍ.

ماذا تعلمت
-----------
  - كيفية الانتقال من استعلام SQL ثابت إلى لوحة تحكم Excel ديناميكية.
  - قوة PivotTables في تلخيص البيانات بسرعة دون معادلات معقدة.
  - تحسين تجربة المستخدم باستخدام Slicers والتصميم المرتب.
